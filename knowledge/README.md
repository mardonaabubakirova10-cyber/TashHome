# База знаний ассистента

Документы в этой папке индексируются командой `npm run kb:index` (из папки `server`) и становятся источником ответов ИИ-ассистента.

**Важно перед защитой.** Тексты написаны как демонстрационные и описывают общий порядок покупки дома. Размеры налогов, пошлин и сроки в законодательстве меняются, поэтому в документах они намеренно даны без точных цифр, с отсылкой к нотариусу, банку и официальным сервисам. Если в дипломе нужны точные цифры, внесите их сюда, сверив с актуальными источниками, и запустите индексацию снова.

Правила написания: один документ — одна тема, короткие абзацы, заголовки второго уровня (`##`), без выдуманных номеров, адресов и ставок.
