# Набор данных `houses.csv`

Частные дома Ташкента: 3000 строк, 10 столбцов, пропусков нет.

## Откуда данные

**Синтетические.** Открытого набора реальных объявлений по домам Ташкента для проекта найти не удалось,
поэтому данные создаёт скрипт [`../generate_data.py`](../generate_data.py) (фиксированное зерно 42, результат
воспроизводим). Это нужно прямо писать в дипломе: модель обучена на сгенерированных данных, а не на реальных сделках.

Когда появятся реальные объявления, достаточно положить их в `houses.csv` с теми же столбцами и заново
запустить обучение, остальной код менять не нужно.

## Столбцы

| Столбец | Смысл |
|---|---|
| `id` | номер строки |
| `district` | район Ташкента (12 значений, как на сайте) |
| `area_m2` | площадь дома, м² (45–450) |
| `land_sotka` | площадь участка, соток (2–40, шаг 0,5) |
| `rooms` | число комнат (2–9) |
| `floors` | этажей в доме (1–3) |
| `building_type` | материал стен: `brick` / `block` / `monolith` |
| `renovation` | ремонт: `none` / `basic` / `euro` / `designer` |
| `year_built` | год постройки (1961–2026) |
| `price_usd` | цена продажи, USD (**целевая переменная**) |

## Как устроена цена в генераторе

```
цена = (площадь × цена_м²_района × ремонт × материал × возраст × этажность + участок × цена_сотки_района) × шум
```

- Цена м² и цена сотки зависят от района (центр дороже окраин, значения те же, что в демо-данных сайта).
- Коэффициент ремонта: без ремонта 0,80, косметический 0,93, евро 1,08, дизайнерский 1,25.
- Материал: кирпич 1,05, блок 0,95, монолит 1,10. Возраст: −0,6 % за год (не ниже 0,65), новый дом (до 5 лет) +5 %.
- Каждый лишний этаж +2 %.
- Шум: логнормальный, около ±10 %. Ещё у 2 % объявлений цена «странная» (×0,6 или ×1,5): выбросы, как в реальных данных.
- Дома окраин в среднем с бо́льшими участками, старые дома чаще без ремонта, большие дома чаще многоэтажные.

## Ограничения

- Модель выучит ровно эти правила. Реальный рынок сложнее (вид, дорога, юридический статус, торг).
- Оценка ориентировочная и не заменяет оценщика.
