# ML: оценка стоимости дома

Модель по параметрам дома (район, площадь дома и участка, комнаты, этажность, материал, ремонт, год) оценивает цену.
Данные и их происхождение — в [`data/README.md`](data/README.md).

## Подготовка (один раз, из папки `ml`)

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Данные

```bash
.venv\Scripts\python generate_data.py
```

## Разведка данных (графики для диплома)

```bash
.venv\Scripts\python eda.py
```

Результат: `reports/eda/*.png` и `reports/eda/summary.txt`.

## Обучение модели

```bash
.venv\Scripts\python train.py
```

Результат: `model/model.joblib` (модель + границы диапазона), `model/metrics.json` (все метрики), графики в `reports/model/`.

## Результаты на тесте (600 домов, которых модель не видела)

| Модель | Средняя ошибка | MAPE | R² | Попадание в ±10 % | Попадание в ±20 % |
|---|---|---|---|---|---|
| Линейная регрессия (базовая) | $12 887 | 10,9 % | 0,828 | 58,2 % | 87,0 % |
| **LightGBM** | **$12 001** | **10,2 %** | **0,854** | 58,8 % | 89,2 % |

- Цель проекта (MAPE не больше 15 %) выполнена. Кросс-валидация на 5 блоках даёт тот же результат (MAPE 10,1 %).
- Диапазон цены (80 %) после калибровки накрывает 78,3 % настоящих цен.
- Сильнее всего на цену влияют площадь дома (37 %), район (25 %) и площадь участка (15 %).
- Обратите внимание: в данных заложен случайный шум около ±10 % и 2 % выбросов, поэтому ошибка около 10 % — это почти нижний предел для любой модели. LightGBM лишь немного лучше линейной модели, потому что цена в генераторе почти мультипликативна. На реальных данных разница, как правило, больше.
