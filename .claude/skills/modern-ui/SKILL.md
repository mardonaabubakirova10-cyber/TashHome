# Современный UI для TashHome

Стек: React 19, TypeScript, Tailwind 4, React Router, i18next. Готовые элементы лежат в `web/src/components/ui` — используй их, а не пиши новые.

## Дизайн
- Mobile-first: сначала вёрстка от 360 px, потом `sm:` / `lg:`. На любой ширине нет горизонтальной прокрутки.
- Цвета только из темы (`brand-*`, `slate-*`), без произвольных hex в компонентах.
- Один крупный акцент на экран (главная кнопка), остальное спокойное. Много воздуха: отступы `gap-4`…`gap-16`, скругления `rounded-xl`.
- Типографика: заголовок страницы `text-2xl font-bold`, секции `text-xl`/`text-2xl`, вторичный текст `text-slate-600`.
- Карточки объектов: фото 4:3, цена крупно и жирно, характеристики одной строкой, метка сделки сверху.

## Состояния (обязательно для каждой страницы с данными)
- Загрузка → `Skeleton`, ошибка → понятный текст + «Повторить», пусто → пояснение и что делать.
- Кнопка в процессе → `loading`, неактивна → `disabled`.
- Фокус виден (`focus-visible`), у картинок `alt`, у иконок-кнопок `aria-label`, контраст текста не ниже AA.

## Тексты и языки
- Никаких строк в JSX: всё через `t('…')`, ключи добавляются **сразу в `ru.json` и `uz.json`**.
- Русские множественные формы: `_one`, `_few`, `_many`, `_other`.
- Деньги только через `useCurrency().format(usd)` (USD ⇄ UZS), цены в данных хранятся в USD.

## Фильтры и ссылки
- Состояние фильтров и страницы лежит в URL (`useSearchParams`), чтобы ссылкой можно было поделиться.

## Проверка перед коммитом
1. `npm run build` без ошибок.
2. Открыть страницу в браузере на ширине 375 px и на десктопе.
3. Переключить RU/UZ и USD/UZS.
