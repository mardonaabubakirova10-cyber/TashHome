# Uy AI — ИИ-платформа агентства недвижимости (Ташкент)

Дипломный проект по курсу «Разработчик ИИ»: сайт и Telegram Mini App с ИИ-ассистентом, оценкой стоимости квартир, ипотечным калькулятором, заявками, отзывами и админкой.

## Документация
- [PRD.md](PRD.md) — что и зачем делаем
- [SPEC.md](SPEC.md) — техническая спецификация
- [TASKS.md](TASKS.md) — план работ по шагам

## Структура
| Папка | Назначение |
|---|---|
| `web/` | React-приложение: сайт, Mini App, админка |
| `server/` | Node.js API, ИИ-ассистент, Telegram-бот |
| `ml/` | Модель оценки стоимости (Python) |
| `supabase/` | Миграции и демо-данные |
| `knowledge/` | Документы базы знаний ассистента |

## Запуск
Появится по мере разработки. Переменные окружения — в `.env.example` (скопируйте в `.env` и заполните).
