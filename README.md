# TashHome — покупка частных домов в Ташкенте

<img src="brand/telegram-avatar.png" alt="Логотип TashHome: телебашня с флагом" width="160">

Дипломный проект: многостраничный сайт агентства недвижимости с ИИ-ассистентом, оценкой цены дома моделью машинного обучения, ипотечным калькулятором, админ-панелью, Telegram-ботом и Telegram Mini App.

**Сайт:** https://tash-home.vercel.app · **бот и Mini App:** [@tashhomeebot](https://t.me/tashhomeebot)

## Что умеет

| Часть | Возможности |
|---|---|
| **Сайт** (React) | Главная со вступлением и 3D-оформлением (Ташкентская телебашня, базар Чорсу), каталог с фильтрами и картой, страница дома (фото, 3D-схема, оценка цены, ипотека), сравнение, избранное, отзывы, ассистент на весь экран, регистрация и личный кабинет по почте и паролю (без регистрации всё тоже работает). Русский и узбекский язык |
| **ИИ-ассистент** (Gemini) | Подбор домов по запросу на живом языке, ответы по базе знаний (RAG), голосовой ввод, запись на просмотр, поиск по фото и описание фото |
| **Оценка цены** (Python, LightGBM) | Оценка стоимости по параметрам дома, метка «ниже рынка / по рынку / выше рынка» в каталоге |
| **Админка** | Статистика и графики, заявки со статусами, дома (добавление, правка, загрузка фото), отзывы с анализом тональности, база знаний, редактирование текстов главной. Вход по почте или короткому логину |
| **Telegram-бот** | Подбор домов, заявки с кнопками для менеджеров, связь клиента с менеджером прямо в чате (обратная связь) |
| **Mini App** | Тот же сайт внутри Telegram, вход по подписи Telegram |

Оплаты в проекте нет: по заданию она необязательна.

## Архитектура

```
Браузер / Telegram Mini App ──► web (React, Vite)
                                   │ HTTPS /api
                                   ▼
                              server (Express) ──► Gemini (чат, эмбеддинги, голос)
                               │   │   │
                               │   │   └──► ml (FastAPI + LightGBM): оценка цены
                               │   └──────► Telegram Bot API (бот, уведомления менеджерам)
                               ▼
                           Supabase: Postgres + pgvector, Auth, Storage
```

Подробные схемы (архитектура, база данных, поток ассистента) в [docs/DIPLOMA.md](docs/DIPLOMA.md).

| Папка | Содержимое |
|---|---|
| `web/` | React 19, TypeScript, Tailwind 4, react-query, i18n, Three.js, Leaflet |
| `server/` | Express 5, Zod, grammY (бот), агент ассистента, тесты (vitest), оценка качества (`eval/`) |
| `ml/` | Данные, обучение и сервис оценки цены (FastAPI) |
| `supabase/` | Миграции SQL (0001–0007) и `setup.sql` |
| `knowledge/` | Документы базы знаний ассистента |
| `lighthouse/` | Отчёт Lighthouse |

## Запуск на своём компьютере

Нужны Node.js 20+, Python 3.11+ и проект в Supabase (бесплатный).

1. Скопируйте `.env.example` в `.env` и заполните (как получить каждый ключ — в [KEYS.md](KEYS.md)). Файл `.env` в git не попадает.
2. База: в Supabase → SQL Editor выполните `supabase/setup.sql`.
3. Установка и запуск:

```powershell
cd server; npm install; npm run dev        # API на :3000
cd web; npm install; npm run dev           # сайт на :5173
cd ml; python -m venv .venv; .venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn service:app --port 8001   # оценка цены
```

4. Один раз наполнить данные для ассистента: `npm run kb:index`, `npm run props:embed`, `npm run props:score` (из папки `server`).

Публикация (Vercel и Render) описана в [DEPLOY.md](DEPLOY.md).

## Проверка качества

- Тесты: `npm test` в `server` (200 тестов) и `pytest` в `ml` (сервис оценки цены).
- Оценка ассистента: `npm run eval` в `server`. Результат: подбор домов 30 из 30, ответы по базе знаний 95 % полностью верно, выдуманных ответов 0 ([подробно](server/eval/results/latest.md)).
- Модель цены: MAPE 10,2 %, R² 0,854 на 600 домах, которых модель не видела ([подробно](ml/README.md)).
- Lighthouse (мобильный, опубликованный сайт): доступность, практики и SEO по 100, скорость каталога 93, главной 52 ([подробно](lighthouse/README.md)).

## Безопасность

Ключи только в `.env`; роли клиент / менеджер / админ проверяются на сервере; права на строки в базе (RLS); проверка загружаемых картинок по содержимому; подпись данных Telegram Mini App проверяется на сервере; всё, что присылает модель, проверяется схемами Zod до выполнения.
